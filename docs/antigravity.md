# Appner in Antigravity CLI

**English** · [Español](antigravity.es.md)

Antigravity CLI installs plugins from a folder on your computer, so first get a copy of this
repository, then install it from that folder.

1. Download the repository: on https://github.com/appner-iot/ai-connect choose **Code →
   Download ZIP** and unzip it, or clone it with git.
2. Install the plugin from the folder you got, for example:

   ```
   agy plugin install ./ai-connect
   ```

3. Start `agy`, open `/plugin`, expand **appner** under Installed and choose **Sign in**. Sign in
   with your Appner email, password and company name (tenant). Do this once, right after
   installing; you stay signed in while you use it at least once a month.

If you already installed the Appner extension in Gemini CLI, `agy plugin import gemini` brings it
over instead.
