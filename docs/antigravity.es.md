# Appner en Antigravity CLI

[English](antigravity.md) · **Español**

Antigravity CLI instala plugins desde una carpeta de tu computadora, así que primero obtén una
copia de este repositorio y después instálalo desde esa carpeta.

1. Descarga el repositorio: en https://github.com/appner-iot/ai-connect elige **Code →
   Download ZIP** y descomprímelo, o clónalo con git.
2. Instala el plugin desde la carpeta que obtuviste, por ejemplo:

   ```
   agy plugin install ./ai-connect
   ```

3. Inicia `agy`, abre `/plugin`, despliega **appner** en Installed y elige **Sign in**. Inicia
   sesión con tu correo, tu contraseña y el nombre de tu empresa (tenant) en Appner. Hazlo una vez,
   justo después de instalar; la sesión se mantiene mientras lo uses al menos una vez al mes.

Si ya instalaste la extensión de Appner en Gemini CLI, `agy plugin import gemini` la trae en su
lugar.
